# Railway Reservation System 🚆

A Railway Reservation System developed using Python and MySQL for managing train details, ticket booking, cancellation, and passenger feedback.

## Features

* Admin Login System
* Add Trains
* Edit Train Details
* Delete Trains
* View Train Information
* Ticket Booking
* Ticket Cancellation
* Passenger Feedback System
* MySQL Database Connectivity

## Technologies Used

* Python
* MySQL
* Tabulate Library

## Database Tables

* Trains
* Bookings
* Feedbacks

## Project Description

This project is a console-based Railway Management System that allows administrators to manage train records and passengers to book or cancel tickets. The system stores data using MySQL and displays records in a formatted table using the Tabulate library.
